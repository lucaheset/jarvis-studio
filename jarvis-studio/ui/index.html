CONFIGURAR ÁUDIO

Use ASIO sempre que der: é o de menor atraso. Se a placa não tiver driver ASIO, instale o ASIO4ALL ou use WASAPI exclusivo. Feche o Reaper (ou outro programa usando ASIO) antes, porque a maioria dos drivers só deixa um programa por vez. Comece com buffer 256; se estalar, suba para 512.
